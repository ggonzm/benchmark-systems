# API reference

Use the public imports shown in this reference. Numerical models are
available from both `benchmark_systems` and `benchmark_systems.models`;
the functions and state conventions are the same through either path.

```{toctree}
:maxdepth: 2

symbolic

```

The [model catalogue](../models.md) lists state layouts, inputs, units and
domain restrictions. For complete workflows, see the
[numerical simulation](../numerical.md), [symbolic modelling](../symbolic.md)
and [animation](../animations.md) guides.
